Paintings Behind Cobwebs - Fabric 1.21.4

BUDOWANIE:
1. Zainstaluj JDK 21.
2. Skopiuj z https://github.com/FabricMC/fabric-example-mod pliki:
   gradlew, gradlew.bat oraz folder gradle/ (wrapper) do tego folderu.
3. Uruchom: ./gradlew build   (Windows: gradlew build)
4. Gotowy mod: build/libs/webpaintings-1.0.0.jar
5. Wrzuc do mods/ razem z Fabric API.

Alternatywnie: otworz folder w IntelliJ IDEA (Gradle importuje sie sam).
